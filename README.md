# Веб-додаток для СТО "АвтоКомфорт"

Це простий веб-додаток, створений за допомогою мови Python та фреймворку Flask. Він призначений для автоматизації процесу запису клієнтів на станцію технічного обслуговування (СТО) та зручного перегляду заявок адміністратором.

##  Використані технології
* **Backend:** Python 3, Flask
* **База даних:** SQLite3
* **Frontend:** HTML, CSS (вбудовані стилі)

##  Основний функціонал
1. **Клієнтська частина (Головна сторінка):**
   * Перегляд актуального прайс-листа на послуги СТО.
   * Форма для запису на обслуговування (ім'я, телефон, вибір послуги).
2. **Панель адміністратора:**
   * Перегляд усіх залишених заявок у вигляді зручної таблиці.
   * Відображення деталей заявки: ID, ім'я клієнта, телефон, назва послуги та її вартість.

##  Структура проєкту
* `app.py` — головний файл веб-додатка, який містить налаштування сервера та маршрути (routes).
* `init_db.py` — скрипт для створення таблиць бази даних та її початкового наповнення тестовими даними (послугами та клієнтами).
* `sto.db` — локальний файл бази даних SQLite.
* `templates/index.html` — шаблон головної сторінки клієнта.
* `templates/admin.html` — шаблон сторінки панелі адміністратора.
